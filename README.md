# Robot-Face

From the Robot Face assignment on Code.org JavaScript curriculum.

**Final grade: 100.** Make sure to complete the project guide fully for 25% of the grade.

## Overview

This project generates a randomized robot face using shapes, colors, and positions that change every time the program is run. It is written using Code.org's App Lab JavaScript environment.

## Features

- Randomized background color generated on each run
- Animated-style antenna orbs with random colors
- Three eyes with randomly positioned pupils
- A triangular head shape
- A colorful mouth
- Shoes (bonus feature!)

## How to Run

Open the project in [Code.org App Lab](https://code.org/educate/applab) and paste the contents of `ROBOTFACE.js` into the editor, then click **Run**.

## Rubric

Fulfills all criteria in:

- **Program development**
  - Shapes appear as coded.
- **Position**
  - Used at least 4 different types of shapes (circle, triangle, rectangle, and line).
- **Variables / Storing information**
  - Uses more than 4 variables with descriptive names and uses the `randomNumber` command to make it look different every time it is run.
- **Creating a digital artifact**
  - Used elements as described in the project guide and clearly displays a robot face.
