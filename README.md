# Robot-Face
From the Robot Face assignment on Code.org javascript curriculum.

Final grade: 100. Make sure to complete project guide fully for 25% of the grade.

# Rubric
Fufills all criteria in:
- Program development
  - Shapes appears as coded.
- Position
  - Used at least 4 different types of shapes (circle, triange, rectangle, and line).
- Variables/Storing information
  - Uses more then 4 variables with descriptive names and use the randomNumber command to make it look different every time it is run.
- Creating a digital artifact
  - Used elements as described in project guide and clearly displayed a robot face.
- It even has shoes!
  - Not part of the criteria but pretty cool anyway!
